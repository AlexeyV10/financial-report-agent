# WIN-09 · Просмотр документа и точный источник

Продолжай финансового ассистента «Проектная практика». Сверь AGENTS.md,
STATUS.md, рабочий handoff, Windows-роадмап, отчёт WIN-08 и зависимости
WIN-07/08. Создай отдельную ветку от проверенного результата WIN-08.

1. Открывай сохранённый оригинал только по известному ID ресурса выбранного
   vault и точной версии из результата службы. Сопоставь внутренний ID,
   SHA-256, логический индекс PDF и печатную метку. Сбрось цель просмотра
   и поздние ответы при переключении проекта. Не принимай произвольные пути.
2. Подключи сменяемый рендерер к WPF. Загружай только запрошенную страницу.
   Покажи рамку ячейки, масштаб и прокрутку. Предусмотри текстовое и табличное
   чтение того же источника с клавиатуры. Сохрани проверку исходных прав
   и лицензий. Укажи границы поддерживаемых локаторов PDF и будущей таблицы.
3. Прогони собственные фикстуры для поворотов, обрезки, попадания рамки
   в изображение, увеличения, DPI, ленивой загрузки и различия между
   печатной страницей и индексом. Покажи отказ при неподтверждённом ID,
   подменённом источнике и выходе за лимиты. Viewer показывает сохранённое
   доказательство, а новая финансовая сверка проводится отдельно.
4. Доведи предыдущие проверки доступности при доступной среде. Запиши
   фактические результаты, хеши неизменённых учебных материалов, статус,
   PR и самостоятельный промт WIN-10. Продолжай по зависимостям.
