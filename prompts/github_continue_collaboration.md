## Доступ, запуск и изменения

- Для первого запуска без PDF/модели из корня копии: python -I scripts/run_local.py fixed --source manual; затем отдельно python -I scripts/run_local.py scenario. Manual использует прежнюю ручную разметку, synthetic явно вымышленный. Настоящий запрет: python -I scripts/run_local.py scenario --case real-source.
- Пустая tmp/ создаётся локально перед старыми тестами: python -c "from pathlib import Path; Path('tmp').mkdir(exist_ok=True)". Значимые изменения кода проверяй подходящими тестами, не запускай весь набор/модель ради правки текста. Полная инструкция — docs/local_demo.md.
- Первичные PDF/страницы/полный текст/индекс, бинарники/веса/ключи/.env не входят в Git. Два PDF собственных материалов и четыре проверенныхZIP разрешены только по точным именам. .gitattributes сохраняет исходные байты ради замороженных SHA; не нормализуй массово LF/CRLF и BOM. В scripts/local_model.ps1 был замечен UTF8 BOM при неизменном остальном тексте; текущую версию сохранять.
- Настоящая модель осталась только в исходной tmp/:Ollama0.40.15/qwen3:4bQ4_K_M2497293931байт,digest359d7dd4bcdab3d86b87d73ac27966f4dbb9f5efdfcc75d34a8764a09474fae7. Не скачивать модель/не подключать платный API автоматически ради клонирования; это отдельная существенная задача, если пользователь её поручит. Недоступную LLM не подменять mock.
- Работай в отдельной ветке под конкретную задачу, сохраняй чужие правки и фиксируй собственные файлы.
