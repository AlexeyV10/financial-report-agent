# WIN-11 · Безопасный универсальный импорт

Продолжай финансового ассистента «Проектная практика». Прочитай AGENTS.md,
STATUS.md, рабочие разделы handoff, Windows-роадмап и отчёты WIN-06, WIN-07,
WIN-08 и WIN-10. Проверь фактические пункты гостевой приёмки D0 и их
квитанции. Создай отдельную ветку WIN-11 от проверенного WIN-10.

1. Определяй формат по содержимому. Сохраняй точные байты с SHA-256 в
   выбранное хранилище, отдельно отмечай дубликат. Соблюдай лимит размера,
   числа страниц, элементов архива, глубины и суммарного распакованного
   объёма до передачи дальнейшим обработчикам. Покажи понятные состояния
   шифрования, повреждения и неподдерживаемого формата.
2. Проверяй пути внутри контейнера до распаковки. Внешние ссылки,
   вложенные исполняемые компоненты, макросы и JavaScript не запускаются.
   Отдельно проверь приём файла, извлечение текста и смысловую проверку.
   Факт загрузки файла сам по себе не допускает ни одного финансового числа.
3. Прогони собственные небольшие фикстуры для опасных записей архива,
   лимитов и повреждения. Проверь отмену, отсутствие частичного импорта,
   разделение хранилищ и повтор прежнего сквозного D0.
4. Сохрани обезличенные доказательства, границы форматов, статус и
   самостоятельный промт WIN-12. Публикуй код и разрешённые артефакты
   отдельной веткой и PR.
