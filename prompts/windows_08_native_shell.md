# WIN-08 · Нативная оболочка финансового ассистента

Продолжай проект «Проектная практика» по `docs/windows/roadmap.json`. После
сверки фактического WIN-07 создай свою ветку от проверенного состояния. Прочитай
AGENTS.md, STATUS.md, рабочий handoff, Windows-план и описания WIN-04–07.

1. Собери WPF-оболочку с бело-зелёным оформлением. Сделай рабочие разделы
   «Проекты», «Документы» и «Анализ». Каждая кнопка должна выполнять понятное
   действие на имеющейся поддерживаемой операции. Покажи пустое состояние,
   выполняющееся задание, успех и технический отказ.
2. Передавай данные через общий сервис и выбранное хранилище. Не вычисляй
   финансовое значение в UI. Пробный собственный PDF даёт `15.00` и ссылку на
   источник. Хранилище и состояние задания не смешивай между двумя проектами.
3. Проверь настоящую навигацию с клавиатуры, видимый фокус, длинные русские
   подписи, свойства UI Automation, системные 125–200% и слышимое чтение
   Narrator. Зафиксируй фактически наблюдавшийся режим. Проверь отдельные
   ранее незакрытые гостевые пункты WIN-02B при наличии подходящего режима.
4. Сохрани результаты, реальные ограничения, новый промт и PR. Не заменяй
   визуальную проверку наличием скомпилированного окна. Продолжай по
   зависимостям к WIN-09 после проверки.
