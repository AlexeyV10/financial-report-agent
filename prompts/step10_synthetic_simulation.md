Для timestamp после закрытия — последующая разрешённая сессия; для date без времени — не раньше следующей сессии после даты; для выходного — следующая заданная сессия. 5. Модель не выбирает цены/даты/операции и не пишет исполняемый код. Здесь торговая арифметика — новый отдельный предмет, а не второй калькулятор годового роста.
6. Подготовь простой независимый контроль журнала.
