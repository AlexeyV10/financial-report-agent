Переходы: ready→search; complete search→get_verified_fact по каждому требуемому ID→calculate→terminal receipt→finish. До calculate разрешён только увеличенный top_k, он очищает fetched IDs и receipts. Partial на максимуме, automatic, publication block или technical tool error создают terminal receipt, далее только finish. После calculate повторный search запрещён. Неверные/повторные вызовы расходуют решения. Последнее решение резервируется под finish limit receipt, если расчёт ещё не закончен. Не завершённый моделью расчёт не публикуется как финансовый ответ.
