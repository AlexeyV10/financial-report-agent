# WIN-10 · Пять операций в Windows

WPF и установленный командный клиент вызывают прежний сервис B. Он
выполняет подготовленный поиск, сверяет факты с источником, рассчитывает
результат и повторно проверяет привязку. В режиме D0 используется собственный
PDF учебной группы по МСФО. Три ячейки исходника отдельно сверены по координатам
в PDF. Дата публикации этой версии источника неизвестна.

| Операция | Подтверждённый результат |
| --- | --- |
| Значение выручки за 2025 год | 120 млн руб. |
| Изменение выручки к 2024 году | 20 млн руб. |
| Относительное изменение выручки | 20,00% |
| Выручка в миллиардах | 0,12 млрд руб. |
| Операционная маржа | 15,00% |

В интерфейсе проверены поиск документа, пять операций, локальная трасса и
открытие страницы 1 с рамкой вокруг двух ячеек для маржи. По вопросу
«Какая выручка за 2025 год?» требуется назвать организацию. Исторический
режим отказывается показать число без даты публикации. Командный прогон
отклоняет отсутствующий или повреждённый оригинал и повтор уже сохранённого
запуска. Квитанция другого проекта не разрешает открыть источник.

Чтобы сохранить старые правила B, один отдельный процесс создаёт проверенный
индекс в собственной рабочей папке приложения. Область старой проверки путей
временно ограничена этим точным индексом и закрывается после запроса.
Замороженные модули и финансовый калькулятор сохранены. Ранее принятый
источник доступен из архива при отсутствии файла в папке. Новый расчёт
требует сверить входной файл. Запуск локальный, с private CPython,
без браузера, Streamlit и вызова языковой модели.

Сборка NSIS предназначена для текущего пользователя Windows 11 x64 с
.NET Framework 4.8+. В пакет входят зафиксированные лицензионные материалы
среды. Ярлык запуска подготавливает собственное учебное хранилище только при
первом запуске. Удаление ограничено файлами программы. Пакет предназначен
для локального испытания.

В первом гостевом прогоне мастер установки и ярлык «Пуска» сработали
под обычной учётной записью. Документ нашёлся, затем проба остановилась
на первом расчёте. Квитанция этой сборки указала шаг, но не сохранила
точный код ошибки. Для профиля тестовой Windows возможный путь трассы
составлял 289 символов. В следующей сборке он сокращён до 224 символов.
Отдельная квитанция повторного прогона сохраняет код отказа при сбое.
[Документация Windows о длине пути](https://learn.microsoft.com/en-us/windows/win32/fileio/maximum-file-path-limitation).

В изолированной гостевой Windows 11 Enterprise Evaluation x64 первая
установка запустилась и из мастера, и из меню «Пуск». После удаления
первой сборки и установки исправленной сохранилось прежнее учебное
хранилище. На системных 125% гостевая проба через обработчики WPF
подтвердила все пять значений, поиск, рамку источника, уточнение, отказ
без даты публикации и очистку результата при смене проекта. После
выхода и удаления из проводника подтверждены PDF, SQLite, метаданные
проекта и квитанции. Итоговая квитанция повторно открыта с диска.

просмотрщика WIN-09. Системные 200%, полный независимый клавиатурный
маршрут и слышимый Narrator остаются в общей приёмке доступности.
