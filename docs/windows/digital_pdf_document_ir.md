# WIN-13 · Цифровой PDF с привязкой к источнику

Импорт сохраняет исходный PDF. Команда «Извлечь содержимое» в разделе
«Документы» читает копию из выбранного проекта и проверяет её SHA-256.
Она сохраняет результат в локальной квитанции
`runs/win13-pdf-ir-v1-<sha256>.json`. Повторная обработка сверяет всё
содержимое. Программа показывает короткий предпросмотр с номером страницы
и оставляет содержательную проверку в состоянии `not_reviewed`.

Результат содержит физический индекс страницы, отдельную метку PDF и
отдельный печатный номер, когда его видно в подписи на странице. У каждого
фрагмента есть полуоткрытый диапазон символов PDFium и две рамки. Первая
задана в исходных координатах PDF, вторая учитывает область обрезки и
поворот и имеет начало в левом верхнем углу. Версии PDFium, pypdfium2,
конфигурации и среды сопровождаются хешами. [Интерфейс текста PDFium](https://pdfium.googlesource.com/pdfium/+/refs/heads/main/public/fpdf_text.h)

Табличные кандидаты сохраняют исходную запись числа и нормализованную
десятичную строку. Связь с периодом и единицами строится по заголовкам и
координатам. Перенос связывается только при наблюдаемой совместимости
страниц и колонок. Неявные заголовки, единицы или разрыв дают
`waiting_context`. Ячейки не поступают в поиск и расчёты. Для страниц
без цифрового текста предусмотрено состояние ожидания OCR. При полностью
растровом PDF квитанция цифрового извлечения не создаётся.

Проверка использует вымышленные документы с известными позициями текста,
числами и подписями. Сквозной тест запускает установленную WPF-сборку и
штатный Python Windows, извлекает две страницы, повторяет команду,
переключает проект и сверяет исходные байты. Дополнительные тесты проверяют
четыре поворота, эффективную область обрезки, две колонки текста,
раздельные метки страниц и обработку растровой страницы. Результаты
относятся к проверенным шаблонам. Распознавание произвольных отчётов и
OCR требуют отдельной оценки.

Открытие и выбор в системном диалоге, озвучивание экранным диктором и
полный ручной обход с клавиатуры в этом прогоне не измерялись. Исходники
загруженных документов и полные результаты извлечения остаются в
локальном хранилище. В Git сохранены генераторы собственных примеров
и сводные результаты.
