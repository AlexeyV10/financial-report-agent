# WIN-08 · Нативная оболочка Windows

В сборке WPF работают разделы «Проекты», «Документы» и «Анализ». Можно
выбрать одно из двух учебных хранилищ, сохранить свой учебный PDF, найти
его по тексту и вычислить операционную маржу. Расчёт выполняет Python-служба
под управлением диспетчера WIN-06. Оболочка отображает готовое значение
и номер страницы источника.

Проверка установленной сборки вызвала восемь действий через обработчики WPF.
В проекте А проверены пустое состояние, импорт, поиск и результат 15,00%
со страницей 1. В проекте Б с отсутствующим исходником появилось сообщение
об ошибке и пустое поле результата. При возврате в проект А новый расчёт
снова дал 15,00%. В первом проекте сохранены один оригинал и строка FTS5.
В проекте Б отсутствовали база и квитанция успешного расчёта. Установка
сохранила исходные хеши всех 277 файлов, рабочая папка осталась пустой.

Подтверждён системный масштаб Windows 125%. Наблюдатель UI Automation
прочитал в отдельном интерактивном процессе стабильные имена и свойства
навигации на экране «Проекты». В этом наблюдении он не увидел активный
клавиатурный фокус внутри окна. Полный маршрут с клавиатуры, визуальный
фокус на остальных экранах, системный масштаб 200% и слышимое чтение
Narrator остаются в приёмке. Доступ инструмента к окну истёк. Для чистой
гостевой Windows подготовлен и побайтово проверен переносимый образ с
учебными файлами. Гостевой запуск этой сборки пока не подтверждён.

Пройдены 12 проверок typed IPC и 10 проверок хранилища на stock Python.
Отдельный сквозной прогон старого клиента WIN-05 подтвердил 15,00% и
отказ при недоступном источнике. Языковая модель не вызывалась.
