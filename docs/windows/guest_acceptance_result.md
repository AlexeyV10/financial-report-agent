# WIN-02B · Испытание установщика в чистой Windows

19.11.2026. Проверен основной цикл установщика WIN-02 v4 в новой Windows 11
Enterprise Evaluation x64, сборка 26300. Машина работала под обычной учётной
записью при отключённом виртуальном кабеле. Предварительная проверка подтвердила
отсутствие известного системного Python, Ollama и прежней установки приложения.
Проверенный снимок чистой машины создан до подключения тестовых носителей.
[Предварительная квитанция](../../evaluation/windows_vm_install_2026-11-11/preflight-observed-2026-11-19.json).

1. Русский мастер завершил установку для текущего пользователя без наблюдаемого
   запроса повышения прав. Папка установки содержит пробелы и кириллицу. Из
   ярлыка меню «Пуск» появился содержательный первый кадр до работы с приложением.
   В первой попытке выделение ярлыка наблюдалось, его активация не подтверждена.
2. В нативном диалоге открыт установленный собственный учебный PDF. На странице 1
   рамка выделила операционную прибыль 18 млн руб. При выручке 120 млн руб. за 2025
   год приложение показало `15.00%`, формулу и текстовую ссылку на источник.
3. Фоновая задача показала промежуточный шаг 2 из 40. Escape остановил её и оставил
   финансовый ответ пустым. Тестовый сбой worker также оставил пустой ответ.
   Следующий расчёт снова показал `15.00%`.
4. Фиксированная диагностика с рабочего каталога DVD подтвердила частный CPython
   3.12.10 x64, внутренние пути загрузки, `isolated=1`, `no_user_site=1`, SHA PDF и
   значение `15.00`. Сборщик сверил 270 файлов с закреплённым манифестом.
5. После обычного закрытия собственные процессы отсутствовали. Русский мастер
   удалил приложение. После удаления отсутствовали установочная папка, ярлык,
   запись удаления текущего пользователя и собственные процессы. Шесть файлов
   данных, включая собственный контрольный текст, совпали по SHA-256.

На гостевом системном масштабе 125% подтверждены маршруты клавиатуры, видимый
фокус, крупный русский текст и действие системной контрастной темы Aquatic.
После испытания возвращена тема None. На зафиксированном разрешении 1024×768
стандартный список показал только 100% и 125%. Системные 200% и слышимое чтение
результата Narrator остаются непроверенными. Проверочный наблюдатель UI Automation
не создал квитанцию после двух запусков. Данные UIA и память guest неизвестны.

Установка наблюдалась в процессе копирования примерно через 0,9 и 4,9 секунды
после нажатия. Точное время конца установки не измерено. При подтверждённом
повторном запуске окно уже было отрисовано к первому снимку около 1,2 секунды.
Окно исчезло на первой проверке около 0,9 секунды после начала закрытия. Это
грубые наблюдения одной виртуальной машины через VirtualBox, с накладными
расходами инструмента и возможным кешем. Полный процессный пик не измерен.

Статус `guest_workflow_validated_accessibility_pending` фиксирует прохождение
основного цикла установки, вычисления и удаления. Полный набор проверок
доступности остаётся открытым. Версия не меняет границы источников, не проверяет
другие платформы и не устанавливает пригодность к публичному выпуску. Факты и
контрольный PDF вымышлены. Модель не запускалась.
[Структурированный результат](../../evaluation/windows_02b_guest_2026-11-19/report.json).

Далее по плану проверяется новый закреплённый runtime. Отдельно повторить UIA и
Narrator, когда доступны пригодные инструменты, и системные 200% на экране
с соответствующим поддерживаемым режимом. Исходный снимок и проверочные данные
оставлены в госте. [Сценарий WIN-03](../../prompts/windows_03_runtime_regression.md).
