# WIN-09 · Просмотр источника расчёта

Кнопка «Открыть источник расчёта» в разделе «Анализ» открывает страницу
сохранённого учебного PDF. Служба сверяет квитанцию выбранного проекта,
ID ресурса, SHA-256, страницу и рамку, затем читает оригинал из SQLite.
Файл может отсутствовать в исходной папке после импорта. Просмотр из
другого проекта и открытие по произвольному пути получают отказ.

Рендерер готовит одну запрошенную страницу. Масштаб, поворот и обрезка
вокруг ячейки меняют изображение и рамку. Прокрутка двигает уже готовое
изображение. Рядом доступны текст страницы и таблица с двумя строками
проверенного учебного примера. Каждое из трёх обозначений страницы
показано отдельно. Для учебного PDF это страница 1, индекс 0, печатный
номер «1». Метка из словаря PDF отсутствует.

Проверки Python покрыли 64 сочетания поворота, масштаба и DPI со сверкой
реальных пикселей рамки, обрезку у края, загрузку только запрошенной
страницы двухстраничного примера и отдельные печатную метку и метаданные
PDF. После временного удаления файла из папки проекта изображение из
архива совпало побайтово, а квитанция расчёта сохранила прежний SHA-256.
Включены проверки повреждённых сохранённых байтов и ошибочных квитанций.

Сквозная проба WPF на системных 125% показала семь кадров с зелёными
пикселями рамки, проверила масштаб 150%, все углы и обрезку. Обработчик
прокрутки сдвинул видимую часть без повторной отрисовки. После перехода
в проект Б прежний источник исчез, после возврата новый расчёт снова
разрешил его открыть. Параметр 200% проверен на рендерере. Системные
200% и отдельный проход клавиатурой остаются в общей приёмке оболочки.

В одном прогоне повторный расчёт оставил журнал на 90% без квитанции.
Исходный код ошибки Windows не сохранился. На отдельной проверке
удерживаемый файл журнала действительно помешал атомарной замене.
Диспетчер теперь кратко повторяет замену при таком конфликте после
повторной проверки файла. При переполнении диска сразу возвращается
ошибка. Обе проверки и новый сквозной прогон прошли.

Лицензионные материалы PDFium, pypdfium2 и Pillow берутся из закреплённой
сборки WIN-03. Новые бинарные зависимости отсутствуют. Для нынешнего
просмотрщика допущен собственный учебный PDF. Навигация по листу и ячейке
таблицы относится к будущему импорту WIN-12. Просмотр показывает уже
сохранённое доказательство. Финансовая сверка проводится отдельно.
