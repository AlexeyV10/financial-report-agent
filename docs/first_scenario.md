# Первый пользовательский сценарий: годовое изменение выручки

Создан 09.11.2026; исходные документы получены 08.11.2026, Europe/Moscow. Сценарий подготовлен для пользователя и Codex; сверка выполнена ассистентом. Проверки формальных участников не требуются.

**Предполагаемый пользователь:** аналитик, которому нужно быстро проверить изменение одного показателя группы по отчётности. Это учебная персона, без интервью и заказчика.

**Вопрос:** «Как изменилась выручка группы “ФосАгро” по МСФО за 2024 год по сравнению с 2023 годом по выбранной версии отчётности? Укажи оба значения, изменение в млн рублей, процент и страницу».

Пользователь выбирает документ и границу группы явно. Без указания компании/группы и периода будущий интерфейс должен запросить уточнение. Текущий проверяющий код получает уже структурированный запрос; свободный русский вопрос он не разбирает.

| Вход | Значение и источник |
|---|---|
| Граница | ПАО «ФосАгро» и дочерние общества, консолидированная группа |
| Стандарт | МСФО / IFRS; заключение аудитора с оговоркой |
| Показатель | Выручка, строка «Выручка», примечание 6 |

Оба значения проверены в [первичном PDF](https://ar2024.phosagro.ru/pdf/ar/ru/additional-information_financial-statements.pdf#page=4) и отдельно в [релизе эмитента](https://www.phosagro.ru/press/company/fosagro-publikuet-operatsionnye-i-finansovye-rezultaty-za-12-mesyatsev-2024-g/). Подробности проверки и ограничений — [source_verification.md](source_verification.md).

**Эталонный ответ:** «По выбранной версии консолидированной отчётности группы “ФосАгро” по МСФО выручка за 2024 год составила 507 689 млн руб. против 440 304 млн руб. за 2023 год. Увеличение — 67 385 млн руб., или 15,30%. Источник: PDF-страница 4, печатная 320, строка “Выручка”, столбцы 2024 и 2023. Дата первичной публикации именно этой PDF-версии неизвестна; исторический торговый сценарий по ней не допускается».

Формула `annual_growth_v1`: `(current / previous - 1) * 100`, положительная база. Абсолютное изменение: `current - previous`. Исходные суммы хранятся точными десятичными строками в млн рублей. Для арифметики используется `Decimal`, 50 значащих цифр, итог процента до двух знаков `ROUND_HALF_UP`; много знаков внутреннего результата не означает соответствующей точности исходной отчётности. Независимая арифметическая проверка: точная рациональная дробь `1684625/110076` процентов; до одного знака результат совпадает с 15,3% релиза.

**Границы первой версии:** один показатель, группа, МСФО, два соседних полных календарных года, одинаковые валюта и масштаб, одна выбранная версия. Сравнение включает реально опубликованный состав группы каждого года; это номинальная динамика по отчётности, без корректировки на инфляцию, курс, приобретения и изменения состава группы. Не заявлять органический рост, причинный эффект, качество бизнеса или инвестиционный вывод.

**Техническая приёмка:** оба значения находятся по сохранённым локаторам и сверены ассистентом; код показывает числа, исходы и ссылки на оба доказательства; несовместимые интервалы дают `conflict`, недостающее значение — `missing`, нулевая/отрицательная база — `unsupported`, неизвестная публикация в историческом режиме — `missing`. Нулевое текущее значение допустимо и даёт −100%; отсутствие не заменяется нулём. Некорректный JSON/сломанная ссылка ID — ошибка контракта, не финансовый отказ. Модель и поиск для этой приёмки не нужны.
