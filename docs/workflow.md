# Фактический порядок работы

**Подтверждён пользователем 09.11.2026 в этом чате.** Проект фактически делает один пользователь вместе с Codex. Пять именных ролей нужны для формального регламента; они не означают участие пяти людей в разработке, проверке или приёмке.

Все содержательные согласования проводятся только с пользователем. Не нужны подписи, отдельные согласования, запуск на компьютерах или проверки остальных лиц, перечисленных в ролях. Их отсутствие не блокирует технический этап. Прежний лист пяти проверяющих отменён. Локальная папка и архив — выбранное пользователем рабочее место; общий репозиторий и доставка другим лицам не требуются.

Codex самостоятельно выполняет разрешённые технические задачи, сверяет первичные источники, считает кодом, проверяет существенные ошибки и фиксирует реальные результаты. После достаточной проверки технический этап можно завершить и подготовить следующий шаг без нового формального круга одобрения. Пользователь принимает существенные решения, которые нельзя определить из доступного контекста; выполненные рутинные шаги не требуют отдельного подтверждения.

Происхождение проверки сохраняется честно: `assistant_checked` означает сверку ассистентом. `source_checked_by_assistant` в ответе сообщает об этом; это не ожидание разрешения и не отказ. Поле `human_reviewer=null` допустимо и не блокирует продолжение. `human_reviewed` не записывается без фактической пользовательской проверки. Два технических способа сверки не называются двумя независимыми людьми.

Сохраняются проверки чисел, компании/группы, стандартов, периодов, валюты, масштаба, знака, версии и дат. Неизвестная публикация PDF по-прежнему запрещает исторический сценарий; неизвестные права не становятся разрешением на распространение. Эти ограничения относятся к корректности данных, а не к составу команды.

В учебных материалах можно сохранить формальные названия ролей. Нельзя выдавать их за фактически выполненную работу других людей, придумывать подписи, проверки, вклад или утверждать выполнение требований курса без подтверждения. Актуальный регламент сдачи по-прежнему неизвестен; организационный вопрос не блокирует самостоятельную техническую работу.

Это последнее решение пользователя имеет приоритет над старым планом, историческими протоколами и архивными промтами. Правила также сохранены в корневом `AGENTS.md` для следующих обращений.
