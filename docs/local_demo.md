# Восстановление текущего локального проекта — шаг13

Это инструкция технического пакета `kp2-local-step13-v1-2026-11-09.zip`. Проект делает пользователь с Codex; подписи и проверки формальных участников не требуются. Пакет — собственный код, минимальная разметка, собственные synthetic fixtures, тесты, инструкции и выбранные доказательства шагов9–12. История чата, исследования, презентация КП1 и все прежние рабочие файлы этим пакетом целиком не экспортируются.

## Что нужно

Проверяется Windows на имеющемся компьютере, CPython3.14.7. Для основных режимов достаточно стандартной библиотеки: пакеты pip не требуются. Отдельный старый PDF-worker с pdfplumber нужен только для извлечения и не входит в эту проверку. Модель/PDF/индекс — дополнительные локальные ресурсы; в ZIP их нет.

В исходной папке рядом с ZIP лежит `.receipt.json` с SHA-256 архива. Внутренний PACKAGE_MANIFEST.json содержит размер/хеш каждого файла, `packaging/kp2_local_v1_files.json` — точный список. Проверка целостности не удостоверяет личность автора, а наличие ZIP само по себе не доказывает запуск. Новые receipt/evaluation шага13 подтверждают отдельно распакованный запуск. Архив stage1-local-v2 исторический, не заменяет текущий код.

## Проверка и восстановление

Из исходной папки проекта, по одной команде PowerShell:

```powershell
python scripts\package_project.py verify --archive delivery\kp2-local-step13-v1-2026-11-09.zip --receipt delivery\kp2-local-step13-v1-2026-11-09.receipt.json
```

```powershell
python scripts\package_project.py restore --archive delivery\kp2-local-step13-v1-2026-11-09.zip --receipt delivery\kp2-local-step13-v1-2026-11-09.receipt.json --dest tmp\my-restored-project
```

Нужна новая несуществующая папка строго внутри tmp/. Перед записью проверяются все ZIP-пути/состав/CRC/размеры/хеши; чужая существующая папка не удаляется и не затирается. Восстановитель создаёт пустую рабочую tmp/ внутри новой копии; в ZIP её содержимого нет. При распаковке обычным архиватором тоже выбирайте пустую папку, проверяйте SHA по receipt и создайте в корне копии пустую tmp/ перед тестами (`New-Item -ItemType Directory -Path tmp`). Один прежний тест ожидает её существование; исходники теста/ядра не менялись.

Откройте PowerShell в корне восстановленного проекта. Его относительные пути ниже относятся к этой новой папке. Для отдельной среды можно выполнить `python -m venv --without-pip tmp\venv`. Обычный Windows Python создаёт `tmp\venv\Scripts\python.exe`; фактически установленный здесь MSYS2 UCRT64 Python создал `tmp\venv\bin\python.exe`. Используйте существующий путь, например `& .\tmp\venv\bin\python.exe -I scripts\run_local.py scenario`. Установка пакетов/облака и скачивание модели для минимальных команд не нужны.

## Запуск без PDF и модели

```powershell
python -I scripts\run_local.py fixed --source manual
```

Это явный B/manual: прежняя ручная разметка, без нового поиска/сверки PDF. Видны обе суммы/полные годы/единицы, формула, +67385 млн RUB/+15,30%, два локатора одной таблицы и ограничения публикации/прав/аудита. Это не новый анализ другого отчёта.

```powershell
python -I scripts\run_local.py scenario
```

ИСКУССТВЕННЫЙ сценарий: вымышленные группа/даты/цены; капитал10000→10098 RUB, комиссии2, +0,98%. Это проверка арифметики и времени, не рыночная доходность.

```powershell
python -I scripts\run_local.py agent --adapter mock --source manual
```

Явный C/mock — имитатор действий контроллера, не языковая модель. Он не подменяет отсутствующую настоящую модель автоматически.

```powershell
python -I scripts\run_local.py fixed --year "9 месяцев 2024"
```

Ожидается уточнение периода (exit1), не подстановка полного года. Отдельная проверка настоящего запрета без синтетических цен:

```powershell
python -I scripts\run_local.py scenario --case real-source
```

Результат blocked/publication_unknown, без сделок и доходности. Подпись/время получения не заменяют публикацию версии.

Проверка заморозки и сохранённых метрик без нового ответа модели:

```powershell
python -I scripts\run_local.py questions
```

```powershell
python -I scripts\run_local.py replay --run-dir evaluation\step12_2026-11-09\run-02-environment-retry
```

Replay проверяет хеши и совпадение results; не запускает поиск/калькулятор/симулятор/модель. Числовая задача B/C1/1, отказы B2/2/C1/2, top1 Ccall_limit остаётся ошибкой. Покрытие3/10 financial, один числовой dev-вопрос/два факта/один PDF; общего качества рынка/слепого теста/превосходства C нет. Описание — docs/measurements.md.

Общий короткий прогон перечисленных режимов (8 случаев, включая явную ошибку отсутствующего PDF):

```powershell
python -I scripts\check_local_demo.py minimal
```

Выводы/trace/report попадут в output/step13-minimal/. Этот каталог не затирается повторным запуском. Для новой проверки используйте новую восстановленную папку; старые доказательства сохраняйте. Итоговый выход0 означает совпадение всех ожидаемых исходов, включая уточнение/ошибку зависимости. Launcher принимает только известные режимы, добавляет собственные scripts/src для isolated Python; произвольная shell-команда/код не исполняется. Прежние CLI без -I также сохранены. До launcher обнаружен импорт соседнего assistant при -I; исправление оболочкой не меняет pinned финансовое ядро.

## Настоящая модель — отдельная зависимость

В исходной рабочей папке уже установлены разрешённые переносимые Ollama0.40.15/qwen3:4b Q4_K_M. Digest359d7dd4bcdab3d86b87d73ac27966f4dbb9f5efdfcc75d34a8764a09474fae7, размер2497293931 байт. Config в пакете — открытые pins, не веса. Этот пакет не устанавливает модель с нуля на другом компьютере.

При проверке на имеющемся компьютере запускайте `scripts/local_model.ps1 start` **из исходной папки**, где находятся прежние бинарники/веса; клиент в восстановленной папке обращается к тому же127.0.0.1:11435. OLLAMA_NO_CLOUD=1, никакого автозапуска/внешнего сервера/платного API. Helper в восстановленной папке без бинарников выдаст объяснимое отсутствие ресурса, не скачивает их сам. Старт из песочницы может не читать manifests (Access is denied); на шаге12 помог разрешённый запуск того же helper вне песочницы, pin/права файлов не меняли. Прямой PowerShell7.4+, без вложенного pwsh -File.

Чужой ранее работающий сервер не останавливайте.
